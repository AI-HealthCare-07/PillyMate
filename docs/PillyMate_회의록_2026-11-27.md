# PillyMate 4조 회의록

- **회의 일자:** 2026.11.27 (금)
- **회의 시간:** 오후 2시
- **회의 주제:** 맞춤형 가이드 점검, 화면 개선, API·코드 구조 및 의약품·챗봇 연동 정비

## 1. 주요 논의 및 진행 사항

| 구분 | 주요 내용 | 진행 상태 |
|---|---|---|
| 프로젝트 문서 | 노션 4조 폴더에 PRD, 요구사항 정의서, 디자인, API 명세서, ERD 공유 | 공유 완료 |
| 맞춤형 복약·응급 가이드 | 응급 안내가 생후 3~6개월 영아 기준으로 반복되는 문제 확인. 아이의 나이와 현재 질병(예: 급성 편도염)에 맞는 위험 신호 안내 필요. 처방일 기준 나이 계산 코드는 확인했으며, LLM 응답과 프론트엔드 중 어느 단계에서 반영되지 않는지 점검 예정. 알레르기 정보 반영 여부는 신규 가이드로 재검증 필요 | 원인 점검 중 |
| 아이 등록 및 화면 | 성별 입력란 누락 확인. 이름·나이·체중·알레르기 등 등록 정보의 내부 로직 활용 여부 검토. 모바일 가이드 화면의 과도한 스크롤과 하단 내비게이션 미고정 현상 재현 | 개선 필요 |
| API 및 코드 구조 | 프론트엔드 임시 저장소는 실제 API로 대체 가능한 부분부터 정리하고 미구현 기능은 유지. 기존 처방 확정 API는 유지하고 미연결 챗봇 기능만 분리·연결하는 방안 검토. OCR 필수 정보 누락 시 가이드 생성 여부는 판단 보류 | 방안 검토 |
| 의약품 정보 수집·분류 | 식약처 공식 API 추가 확보 필요. 검색 결과가 많거나 보험코드·용량이 달라 분류에 실패하는 약품 확인. 추정 결과 대신 공식 데이터 기반의 약품 매칭 및 분류 규칙 개선을 우선 진행 | 우선 진행 |
| 챗봇 및 LLM 연동 | 새로고침 후 질문 기록이 사라지는 현상 확인. DB 연동 여부와 처방 정보 외 질문의 답변 범위 점검 필요. 공식 API 응답을 활용해 확인된 정보만 답변하도록 제한하는 방식(RAG), JSON 응답 필드 지정 및 프롬프트 개선 검토. 가이드·챗봇 전용 프롬프트 분리 관리 | 점검 및 검토 |
| 건강 기록 및 복약 기록 | 중복 처방 기록 삭제 시 관련 복약 기록도 함께 삭제되는 동작 확인. 건강 기록은 예방접종 등 처방약 없는 진료도 기록하는 용도. 직접 입력 기록의 수정 기능 부재, 처방약 없음 표시 및 직접 입력 기록 색상 구분 등 디자인 개선 논의 | 개선 논의 (통합 여부 미정) |
| 가이드 생성 중 409 오류 | 가이드 생성 직후 뒤로가기 시 처방 확인 화면으로 돌아가 재생성 요청이 가능한 문제 재현. 생성 중 뒤로가기 방지, 가이드 생성 완료 처방의 확인 화면 재진입 차단, 409 응답 시 화면 전환 중단 및 오류 안내 필요 | 대응 방안 정리 |

## 2. 향후 진행 사항

- 응급 안내에 아이 나이·질병이 반영되지 않는 단계(LLM 응답/프론트엔드) 점검 및 알레르기 반영 재검증
- 아이 등록 성별 입력란 보완, 모바일 가이드 화면 스크롤 길이 및 하단 내비게이션 고정 개선
- 프론트엔드 임시 저장소를 실제 API로 단계적 대체, 챗봇 기능 분리·연결
- 식약처 공식 API 추가 확보 및 공식 데이터 기반 약품 매칭·분류 규칙 개선
- 챗봇 질문 기록 DB 연동, 답변 범위 제한 및 가이드·챗봇 프롬프트 분리
- 건강 기록 수정 기능, 처방약 없음 표시 및 색상 구분 등 디자인 개선
- 가이드 생성 중 뒤로가기 방지, 재진입 차단 및 409 오류 안내 처리

## 3. 멘토링 질문

- OCR 정보가 일부 누락된 경우에도 복약 가이드 생성을 허용할 것인지, 의료적 안전성을 위해 모든 정보가 입력된 경우에만 생성을 허용할 것인지

## 4. 회의 결론

맞춤형 가이드에 아이의 나이·질병·알레르기 정보가 제대로 반영되지 않는 원인을 점검하고, 아이 등록 및 모바일 화면을 개선한다. 의약품 정보는 공식 데이터 기반 매칭을 우선 개선하고, 챗봇은 기록 저장과 답변 범위 제한을 정비한다. OCR 정보 누락 시 가이드 생성 여부는 멘토링 이후 결정한다.
