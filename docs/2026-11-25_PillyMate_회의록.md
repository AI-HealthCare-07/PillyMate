# PillyMate 4조 회의록

- **회의 일자:** 2026.11.25 (수)
- **회의 주제:** 주요 기능 구현 및 점검, 디자인 개선, API 및 DB 설계 정비

## 1. 주요 논의 및 진행 사항

| 구분 | 주요 내용 | 진행 상태 |
|---|---|---|
| 회원가입 및 로그인 | 카카오에서 사용자 정보를 받아오고, 서비스에 필요한 나머지 정보는 추가 입력하는 방식으로 결정. 이후 카카오 재로그인 시 기존 계정과 연동하는 방향으로 진행 | 방향 확정 |
| CI | 프로젝트용 별도 구성 예정 | 사전조사 중 |
| 디자인 | 보호자와 소아청소년에게 적합한 따뜻하고 친근한 디자인으로 수정 | 수정 진행 |
| 주요 기능 | 기존 기능의 작동 여부 확인 및 오류 수정 | 점검 및 수정 |
| OCR | 처방전 정보 추출 기능 구체화 및 OCR API 구현 | 구현 완료 |
| 가이드 API | 복약 및 생활 습관 가이드 API 작동 확인 후 수정 | 점검 및 수정 |
| API 명세서 | 변경된 기능 및 API 연동 내용을 반영하여 명세서 수정 | 수정 작업 |
| ERD | 회원정보, 자녀정보, 처방정보 및 복약기록 등 변경된 데이터 구조를 반영하여 수정 | 수정 작업 |
| 의약품 데이터 | 전체 의약품 대상 약품명 검색, 간단한 약효 설명 표시 및 소아 연령금기 정보 연계 검토 | 검토 중 |
| 개발 환경 | Git dev 브랜치 최신 코드 반영, Docker 및 MySQL 환경, DB 테이블과 마이그레이션 점검 | 점검 진행 |

## 2. 향후 진행 사항

- 카카오 회원가입 및 추가 정보 입력, 재로그인 연동 테스트
- OCR 결과와 의약품 정보, 복약기록 및 AI 가이드 API 연동 확인
- 의약품 데이터 확보 및 소아 연령금기 정보 활용 방안 구체화
- 수정된 API 명세서와 ERD를 실제 구현 코드 및 DB 구조와 대조하고 팀원에게 공유
- 디자인 개선 및 전체 서비스 통합 테스트, 오류 수정
- CI 사전조사 및 적용 방식 검토
- 인증·인가, 비동기 처리 및 P95 응답시간 3초 이내 목표 점검

## 3. 회의 결론

카카오 기반 회원가입 방향을 확정하고 OCR API 구현을 완료하였다. 기존 기능과 가이드 API를 점검·수정하고, 디자인 및 API 명세서와 ERD를 정비한다. 이후 개별 기능 간 연동과 전체 서비스의 안정성 확보에 집중한다.
