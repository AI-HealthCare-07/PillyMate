# 2026.11.26 PillyMate 회의록

## 1. 작업 진행 상황 공유

- 최신 dev 브랜치의 코드를 Pull 받아 팀원별 작업 진행 상황 및 변경 사항 공유
- 현재까지 구현된 기능과 API 연동 상태 확인
- 전체 기능을 점검하면서 추가 구현 및 수정이 필요한 부분 논의

## 2. 주요 논의 및 개선 사항

### 2-1. OCR 및 데이터베이스

- 처방전 및 약봉투 OCR 인식 결과를 보다 정교하게 처리할 수 있도록 개선
- 약품 정보 및 복약 정보의 정확도 향상
- 기능 추가 및 변경에 따른 DB 테이블 구조와 수정 필요 여부 확인

### 2-2. 자녀 및 처방전 관리

- 자녀 정보 수정 및 삭제 기능 활성화
- 등록된 처방전을 삭제할 수 있는 기능 추가
- 수정 및 삭제 시 관련 데이터의 정상적인 반영 여부 확인

### 2-3. 복약 가이드 및 전체 기능 개선

- 복약 가이드 제공 내용을 보다 정교하게 수정하고 필요한 정보 추가
- 프론트엔드와 백엔드 간 기능 및 API 연동 상태 확인
- 전체 서비스 이용 과정에서 발생하는 오류 및 불편 사항 수정
- 추가 구현이나 개선이 필요한 부분은 팀원 간 공유 후 반영

### 2-4. 웹 푸시 및 복약 알림

- 웹 푸시(Web Push) 관련 정보 및 적용 방법 확인
- 브라우저 알림 권한 요청 및 허용·거부 시 처리 방식 확인
- 복약 알림 설정에 따른 실제 알림 표시 여부 점검

## 3. 향후 일정

### 11월 27일(금) 오전

- 팀원별 담당 작업 및 추가 수정 사항 정리
- 작업 내용을 main 브랜치에 Merge하여 전체 코드 통합
- 모든 팀원이 최신 main 브랜치의 코드를 Pull 받아 실행
- 전체 기능의 정상 작동 여부 및 최종 작업 진행 상황 확인
- 통합 이후 발견되는 오류 및 추가 개선 사항 공유

## 4. 기타 사항

- 세부 작업 내용 및 추가 확인 사항은 정린님께서 최종적으로 정리하여 공유해 주시기로 함.
- 내일 오전 중 코드 통합을 진행하고, 전체 팀원이 동일한 코드를 기준으로 프로젝트 진행 상황을 확인하기로 함.
