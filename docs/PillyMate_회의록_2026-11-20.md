- **회의 주제:** MVP 개발 범위 및 향후 작업 협의

## 1. 주요 논의 사항

### 1.1 LLM 가이드 검토
- 정린님이 기초적으로 작성한 가이드를 확인한다.
- 수정 및 보완이 필요한 부분을 검토한다.

### 1.2 1차 요구사항 명세서
- 기존 요구사항 중 **1차 MVP에 포함되는 항목만 별도로 정리**한다.
- 정리한 요구사항 명세서를 팀에 공유한다.

### 1.3 멘토링 일정
- **2회차:** 화요일 19:30 진행 예정
- **3회차:** 오전 진행 가능 여부 추가 협의

### 1.4 API 명세서
- API 명세서를 검토하고 수정 사항을 확인한다.
- 수정 및 협의 후 최종 확정한다.

### 1.5 개발 환경 및 코드 통일
- PyCharm 설치 및 동기화를 진행한다.
- 팀원 간 개발 환경과 코드 설정을 통일한다.

### 1.6 디자인 검토
- 디자인을 확인한 후 작업을 진행한다.

### 1.7 MVP 처리 방식
- **1차 MVP는 동기 처리 방식으로 구현**하기로 협의하였다.
