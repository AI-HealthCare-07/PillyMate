# PillyMate 팀 프로젝트 회의록

**회의 일자:** 2026년 11월 23일 (월)  
**회의 주제:** API 및 ERD 설계 방향 검토, 프론트엔드 기능·디자인 논의

## 1. 금일 진행 내용

### ① API 명세서 및 ERD 관련 논의
- API 명세서가 아직 확정되지 않아 ERD 설계도 진행하지 못한 상태
- 공공데이터포털 API 신청 후 활용 방법 및 자체 DB 구축 가능 여부 검토
- 외부 API 직접 호출 방식과 데이터를 수집하여 자체 API로 제공하는 방식 비교
- 의약품 정보, 약효 분류, 소아 연령금기 등 필요한 데이터와 활용 방향 검토

### ② 프론트엔드 중심 회의
- 기능 개발 담당자들의 부재로 프론트엔드 중심으로 회의 진행
- 현재 구현된 화면의 디자인 및 기능에 대한 의견 공유
- 팀원들과 수정 사항을 확인하며 디자인과 기능을 지속적으로 조정

## 2. 현재 진행 상황
- **API 명세서:** 미확정
- **ERD:** API 명세서 미확정으로 설계 보류
- **공공데이터 API:** 활용 방식 및 필요 데이터 검토
- **프론트엔드:** 디자인 및 기능 수정·검토 진행 중

## 3. 향후 진행 사항
- API 명세서 확정 후 ERD 설계 진행
- 의약품 관련 공공데이터 API의 제공 항목 및 활용 가능 범위 확인
- 프론트엔드 수정 사항 공유 및 팀원 피드백 반영
- 기능 개발 담당자들과 API 연동 및 데이터 구조 협의

## 4. 회의 요약

금일은 기능 개발 담당자들의 부재로 프론트엔드 중심의 회의를 진행하였다. API 명세서가 확정되지 않아 ERD 설계는 보류된 상태이며, 공공데이터 API 활용 방법과 의약품 데이터 구축 방향을 검토하였다. 프론트엔드는 팀원들과 디자인 및 기능을 지속적으로 수정하고 의견을 공유하며 진행하였다.
