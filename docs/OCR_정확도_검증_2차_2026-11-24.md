# OCR 정확도 검증 2차 — 새로 생성한 40장 (2026-11-24)

## 무엇을 했나

- **새 테스트 이미지 40장**: 처방전 20장 + 약봉투 20장을 프로그램으로 생성 (시드 고정, 다시 만들 수 있음)
  - 촬영 조건: 스캔 8장 / 사진 12장 (그중 4장은 **어려운 사진**: 4~8° 기울기 + 원근 왜곡 + 흐림 + 그림자)
  - 내용: 약 17종(시럽·건조시럽·가루·정제·캡슐·좌약·점안액), 한 장에 1~7개, 필요시 약, 질병코드 0~2개, 손가락·배경색·조명 변화
  - **용량은 모두 소수 둘째 자리 이하** (예: 0.25, 0.67, 2.75, 3.25, 6.25)
- **정답은 생성 데이터에서 바로 만듦** → 1차와 달리 파서 결과에 의존하지 않는 진짜 정답
- 실제 CLOVA OCR에 1장씩 보내고(40회) → `run_ocr` 파서 → 정답과 비교
- 약은 순서가 아니라 이름 유사도로 짝지어 비교 (약 하나를 놓쳐도 뒤 약들이 전부 틀리게 나오지 않도록)

| 정답 만드는 법 | 파서 결과를 옮겨서 일부만 사진과 대조 | **생성 데이터에서 바로** (파서와 독립) |

| 처방전 나머지 항목 | 전부 100% | 95~100% (한 줄 전체 정답 89.2%) |

1차에서 100%로 보이던 항목들이 실제로는 문제가 있었다는 것이 정답을 독립적으로 만들자 드러났습니다.
1차에서 발견한 "기울어진 사진에서 용법 앞 단어 잘림"은 이번 40장에서는 재현되지 않았습니다.

## 5. 한 줄 요약 / 다음 작업
